INTERPRETATION GUIDE: Understanding the Results
================================================================================

Why do ADF and KPSS give seemingly opposite results?
--------------------------------------------------------------------------------
This is NOT a contradiction! The two tests have OPPOSITE null hypotheses:

  ADF Test:
    H0 (null hypothesis) = 'The series is NON-stationary'
    If p-value > 0.05 -> Cannot reject H0 -> Series is NON-stationary
    If p-value < 0.05 -> Reject H0 -> Series is STATIONARY

  KPSS Test:
    H0 (null hypothesis) = 'The series is STATIONARY'
    If p-value > 0.05 -> Cannot reject H0 -> Series is STATIONARY
    If p-value < 0.05 -> Reject H0 -> Series is NON-stationary

What this means in practice:
--------------------------------------------------------------------------------
Many patients fall in a 'GREY ZONE' where:
  - ADF cannot find strong enough evidence of stationarity
    -> Classified as 'non-stationary' (shows some progression)
  - KPSS cannot find strong enough evidence of non-stationarity
    -> Classified as 'stationary' (not dramatic changes)

This grey zone typically contains patients with:
  - Mild/moderate disease progression (not dramatic decline)
  - Some variability but with underlying trends
  - Realistic disease dynamics (not static, not extreme)
