
# AD Course Map

AD Course Map is a multivariate mixed-effects statistical model designed for the analysis of longitudinal data, with a specific focus on medical data. It has been used to simulate disease progression, such as Alzheimer's, and to generate synthetic data from real observations.

## Getting Started

### Prerequisites

- Python >= 3.9, < 3.12
- Jupyter Notebook
- Leaspy

### Installation

Clone the repo

    git clone https://github.com/github_username/repo_name.git

Create a conda environment (optional)

    conda create --name <env-name> python=3.10
    conda activate <env-name>

Install the necessary dependencies

    pip install -r requirements.txt

### Folder Structure


- The `root` directory is organized as follows:

    

- The main files for running the model, training, validation, and generating data are located in the `code` folder. 

    ```
    └── 📁code
        └── loader.py
        └── loss.py
        └── main.py
        └── model.py
        └── utils.py
    ```

    The main script can be executed using the command 
    
        python main.py
    
    For more information on the arguments that can be passed to the script, use

        python main.py --help

- The `dataset` folder contains data in CSV format generated by Koval et al. (2021) in [*AD Course Map charts Alzheimer’s disease progression*](https://doi.org/10.1038/s41598-021-87434-1). Can be downloaded at the [site](https://project.inria.fr/digitalbrain/) attached to the article.

    ```
    └── 📁datasets
        └── cognitive_scores.csv
        └── cortical_thickness_1.csv
        └── cortical_thickness_2.csv
        └── cortical_thickness_3.csv
        └── cortical_thickness_4.csv
        └── cortical_thickness_5.csv
    ```

    The file `cognitive_scores.csv` includes data for **1 million subjects**, covering over** 5 million visits**. It contains the following columns: `ID`, `TIME` (age at the time of the visit), `MMSE`, `Memory`, `Language`, `Concentration`, and `Praxis`. The `cortical_thickness` files contain 3658 ROI for 100.000 subjects (500k+ visits) split across 5 files.

- The `notebooks` folder includes scripts that are useful for evaluating and visualizing the results

    ```
    └── 📁notebooks
        └── assessing_mci_age_ranges.ipynb
        └── fit_time.ipynb
        └── main.ipynb
        └── sensitivity_analyses.ipynb
    ```
