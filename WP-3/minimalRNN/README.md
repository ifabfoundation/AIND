# Minimal RNN

Implementation of a Recurrent Neural Network (RNN) in PyTorch. This network is designed to predict the trend of time series, with the aim of generating synthetic data. The network predicts both continuous and categorical variables; the prediction can be conditioned by static, non-time-dependent variables. The network was constructed to work even with incomplete data, exploiting the model's own predictions.

## Getting Started

### Prerequisites

- Python >= 3.9, < 3.12

### Installation

Clone the repo

    git clone https://github.com/<github_username>/<repo_name>.git

Create a conda environment (optional)

    conda create --name <env-name> python=3.10
    conda activate <env-name>

Install the necessary dependencies

    pip install -r requirements.txt

### Folder Structure


- The `root` directory is organized as follows:

    ```
    └── 📁ADCourseMap
        └── 📁code
        └── 📁datasets
        └── 📁results
        └── README.md
        └── requirements.txt
        └── TODO.md
    ```
    
- The main files for running the model, training, validation, and generating data are located in the `code` folder. 

    ```
    └── 📁code
        └── 📁models
        └── 📁loss
        └── 📁utils
        └── loader.py
        └── main.py
    ```

    The main script can be executed using the command 
    
        python main.py
    
    For more information on the arguments that can be passed to the script, use

        python main.py --help

- The `models` folder contains the implementation of the RNN and a single cell of it, together with a customised dataset model.

    ```
    └── 📁models
        └── rnn_cell.py
        └── rnn.py
        └── custom_dataset.py
    ```

- The `utils` folder contains some useful functions and dependencies.

    ```
    └── 📁utils
        └── dependencies.py
        └── functions.py
    ```

- The `results` folder contains the results automatically generated by the code. It will contain a sub-folder for each execution of the code, the name of the sub-folders will consist of the `number of patients`, the `number of epochs` and the `date of execution`.

    ```
    └── 📁results
        └── 📁experiment_<n_patients>_<n_epochs>_<date>
            └── 📁images
            └── 📁weights
    ```

    The images folder contains the training and validation curves, the weights folder contains the model weights that obtained the best result in validation.

- The `dataset` folder should contain the data in csv format, if you want to use a different folder to collect the data or create a sub-folder within it, you must change the paths within the `main.py` file.
